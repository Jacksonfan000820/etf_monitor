# 贡献指南

先阅读根目录 AGENTS.md；修改 market-digest 时也阅读其 AGENTS.md。保留原 ETF CLI 与已有数据库兼容性。

## 工作流程

1. 从最新主分支建立主题分支，先复现问题并运行基线。
2. 添加离线 fixture 或 mock 测试；不将实时报价、真实消息发送或私有导出作为普通测试前置条件。
3. 修改后执行 `python scripts/check.py`。脚本可从任何目录调用。
4. 更新受影响的命令、配置、限制和运行说明。新源需注明单位、时区、字段含义、许可和失败行为。
5. 提交聚焦的改动并创建草稿 PR，写明动机、实际修改、验证命令、未验证部分及回退方式。

建议提交前缀：`fix:`、`feat:`、`docs:`、`test:`、`chore:`。版本发布应以实际功能和兼容性变化为依据，不提前宣称稳定版或生产可用。

## 必须保持的约定

- 缺失不等于零；未知日期不等于最新；来源摘录不等于核实过的事实。
- HTML 输出需转义；网络目的地、重定向、大小、超时和解析资源必须有边界。
- 默认不发送，不自动引入定时或付费来源。
- 数据库迁移优先添加字段，并用旧库 fixture 测试。破坏性变更须单独设计恢复方案。
- 不随意重命名入口、移动数据库位置或将两套 ETF 解析互相替换。
- 禁止提交 .env、webhook、令牌、私有 X 导出、生成报告、数据库、虚拟环境。

## 问题反馈模板

提供 Python/系统版本、提交 SHA、复现命令、预期/实际结果和去敏日志。数据解析问题附最小公共样本、来源链接及采集时间。不要在公开 issue 中上传密钥或私有报告。安全问题参见 [SECURITY.md](SECURITY.md)。
