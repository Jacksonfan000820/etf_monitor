# 完整项目路线图（未完成事项，不是功能声明）

## P0：可部署基线

- 已在整合环境验证真实 XNYS 节假日、提前收盘、夏令时边界，并约束 pandas<3；部署环境仍须重新安装并跑日历回归测试。
- 联网验证 Farside、Fed、SEC、CoinDesk，确认 URL/schema/许可/频率；403 或页面变更时禁用或换获准来源，不绕过访问控制。
- 增加每源健康状态、延迟、最后成功日期和诊断分类；日报总状态区分完整、部分失败、全不可用。当前生成退出成功不表示数据齐全。
- 增加 SQLite 采集记录、不可变原始快照（许可允许时）、修订记录与迁移测试；不要把整份原始新闻长期存储默认当成有授权。
- 飞书签名支持、长度受控分片、投递账本、明确失败与未知结果。自动重试只针对安全读取，发送结果未知先人工核对。
- 在用户确认部署目标/时区/频道后跑 Actions dry run，再验证一次真实飞书并检查接收效果；默认禁止真实发送。

验收：fixture 单测 + 真实源验收报告 + 无密钥发布包 + 首次真实投递经用户批准且可核实。

## P1：完整情报覆盖

- X/KOL：选择官方 API 或许可数据服务，明确账户列表、语言、费用、速率限制与授权；实现分页、增量游标、编辑/删除处理、429 退避、证据与观点来源。当前仅有导入器，尚无 KOL 列表或自动采集。
- 美股：接入有授权的指数/个股价格、财报日历、公司公告、宏观指标，明确实时/延迟、复权和时区。现有 SEC/Fed 只是监管/政策新闻，不提供行情。
- ETF：扩展到用户关心的美股 ETF，区分资金流、价格、成交量、NAV/AUM 与持仓；不得从价格变化推算真实资金流。
- 交易所活动：逐所官方发现适配器，结构化开始/结束时间、地区、KYC、资金门槛、奖励池与领取条件、风险和原文证据；状态机显示待审核/有效/已结束，不推断用户资格。
- 结构化中文日报：新闻事件去重与相互佐证、按重要性排序、可选有来源智能摘要；保留原文引用与推断边界。模型供应商、费用和数据分享需获授权。

验收：每类真实源和降级测试；所有结论可追溯；不夸大“覆盖全部”或“实时”。

## P2：产品与运维

- 按用户优先级选择网页界面/API、搜索、订阅/watchlist、人工审核，不预先强加技术栈。
- 可观测性、运行锁、补跑、跨运行去重、数据质量阈值、告警与灾难恢复；默认关闭无人值守外发。
- 权限隔离、秘密管理、审计、依赖锁与漏洞扫描、数据许可/保留策略。
- 长期运行可选择 cron/容器/托管任务，GitHub Actions 仅适合接受延迟的日报，不保证准点 SLA。

最终验收以用户确认的覆盖列表、每日产物、实测数据质量与部署结果为准，代码行数和模块数量不等于完成。
